# Aset produksi hasil generator gambar

Folder ini disediakan untuk ilustrasi pose baru dan latar tema yang dibuat
melalui image-generator AGY berdasarkan referensi pengguna. Gambar referensi
di `assets/sprites/references/` tetap menjadi sumber desain, tidak ditimpa.

Target: dua sprite sheet 3 kolom × 4 baris (Beatrice dan Waguri) serta latar
tema tanpa tulisan untuk Frieren, Beatrice, dan Waguri. Keluaran generator
harus diperiksa sebelum diaktifkan sebagai sprite produksi.
