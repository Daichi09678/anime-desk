# Foto referensi karakter

Tambahkan subfolder `frieren`, `beatrice`, dan `waguri_kaoruko` sesuai kebutuhan.
Simpan referensi PNG/JPG/WebP dengan nama jelas, misalnya `front.png`,
`thinking.png`, `smile.png`, atau `outfit.png`.

Gambar di sini tidak dimuat sebagai sprite aktif oleh aplikasi. Referensi akan
dipakai untuk menyelaraskan desain, proporsi, pose, ekspresi, dan kostum sebelum
menyiapkan aset animasi. Jangan menimpa PNG aktif di folder induk.

Tahapan lengkap: [CHARACTER_PLAN.md](../../../CHARACTER_PLAN.md).
